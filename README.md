# Asansör Düğmelerinin Gizli Günlüğü

> Bu belge, Uluslararası Düğme Duyguları Enstitüsü (UDDE) tarafından *neredeyse* onaylanmıştır.

## Bu nedir?

Her asansör düğmesi gece 03:17'de bir defter açar.  
Kimse sormaz. Kimse dinlemez.  
Bu proje o defteri okur.

Kod **gerçekten çalışır**. Duyguların çalışıp çalışmadığı ayrı bir tartışmadır.

## Kurulum

```bash
python3 gunluk.py
```

Python 3 yeter. Çay opsiyonel ama tavsiye edilir.

## Örnek çıktı

```
[KAT 7] Bugün üç kez basıldım. Biri pişman olup 4'e indirdi. Affetmiyorum.
[ACİL] Yine kimse beni acil için kullanmadı. İyi. Belki.
```

## Mimari

- `gunluk.py` — düğmelerin iç sesi
- `katlar.json` — resmi olmayan resmi kat envanteri
- `LICENSE` — herkes kullanabilir, kimse düğmeye sormadan söz veremez

## Sık sorulan sorular

**Asansör düğmesi gerçekten yazıyor mu?**  
Hayır. Ama kod evet diyor.

**Neden Türkçe?**  
Çünkü 3. kat İngilizce bilmiyor.

**Siyaset var mı?**  
Yok. Her kat eşittir. Bu teknik bir ifadedir.
